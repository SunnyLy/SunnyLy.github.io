# 逆向

这个分类先整理分析方法与记录习惯：把观察到的事实、尚未证实的推测和最终结论分开，降低反复排查的成本。

## 内容整理中

本分类暂未收录正式笔记，后续按实际分析问题逐篇整理。现有工具记录见[工具与实践](/tools/)。

阅读或整理案例时，先明确问题、对象来源、环境和边界，再沿证据回答问题。证据不足时保留待验证状态，不用工具输出的表面结果替代结论。
