# 工具与实践

工具服务于问题和证据。这个分类先整理笔记的呈现与阅读方式，让图片、流程图、代码和文字在同一篇文章里形成完整解释。

## App 网络请求抓包

[App 网络请求抓包](./app-network-capture.html)整理手机 Clash 配置导入、抓包证书与 mitmweb 启动方式，提供配置附件下载和可缩放的代理链路图。

阅读后可以根据[开始阅读](/guide.html)中的格式，添加自己的 Markdown 笔记。优先使用站内素材和可编辑图示源码，让内容易于迁移和长期维护。

## 保留可复用的过程

记录工具时写明它解决什么问题、输入输出是什么、结果怎样验证。只有实际确认过的版本、命令与选项才写成确定步骤；不把未经验证的环境假设复制到后续笔记。
