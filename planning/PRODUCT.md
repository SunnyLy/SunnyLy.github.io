# 技术知识库产品约定

## 目标与范围

把现有静态博客升级为中文技术知识库：读者通过 GitHub Pages 的 HTTPS 地址，在手机或电脑浏览器直接阅读、搜索和分享独立文章。首版采用 VitePress，保留旧文章、相册、静态资源、App Links 和安装入口；不改写 `AGENTS.md`，不提交或推送代码。

首版提供完整导航和真实可用的示例内容，不编造文章数量、更新时间、阅读量或学习进度。研究结论由主控补充到研究文档；本文件约束交互与验收。

## 页面与信息架构

- 首页：简洁品牌区、知识分类入口、精选入门路径与内容维护说明。避免占满首屏的装饰，让读者迅速进入文章。
- 分类页：介绍学习范围，列出实际存在的文章，标明建议阅读顺序；未完成内容明确说明，不能放无效链接。
- 文档页：桌面左侧分类树、中央正文、右侧本文目录；手机使用顶部导航抽屉和可展开本文目录，正文优先。
- 搜索：全站本地搜索，覆盖标题与正文；支持中文关键词、键盘选择、明确的无结果状态及点击跳转。
- 旧内容：提供明确的旧博客入口，原路径继续访问，旧文章图片保持可用。

分类定义以 `docs/.vitepress/navigation.ts` 的 `knowledgeSections` 数组为单一真相源，包含 `android`、`security`、`reverse`、`tools`。首页入口、导航和任何分类计数从该配置派生，不在文档或组件中另写共享数量。

## 视觉与阅读

采用克制的技术编辑风格：清晰中文排版、舒适行距、适度正文宽度、低噪声背景与统一强调色。导航层级、当前文章、搜索入口须清楚可辨。支持明暗主题，颜色对比、键盘焦点和触控区域在两种主题下都可用。手机不得出现整页横向滚动；代码与宽表格仅在自身容器内滚动。

## 图片与流程图

- Markdown 图片及正文中的普通 HTML 图片自动适应正文宽度，保持原始比例；点击打开可关闭的查看层，支持缩放与触控操作。键盘可打开、退出，关闭后恢复焦点。
- Mermaid 代码块生成可读流程图；每张图提供放大、缩小、重置及全屏查看入口，支持拖动查看大图和手机触控操作，不能阻断页面正常滚动。
- 图片加载失败、Mermaid 语法错误须有可理解的提示；图示必须保留文本替代或可访问的标题说明。

## 内容约定

文章使用 Markdown，标题描述具体问题。推荐包含适用范围、核心原理、操作或分析步骤、验证结果、参考链接；明确区分事实、示例与待验证结论。示例文章同时展示代码、普通图片、HTML 图片、流程图和长内容阅读体验。内容不得依赖私有账号或付费域名才能阅读。

## 验收

- 在窄屏手机、平板和桌面浏览器验证首页、分类页、正文及直接刷新；链接可分享，主题和导航正常。
- 用实际正文中文关键词搜索并打开命中章节；测试无结果、键盘操作及手机搜索弹层关闭。
- 逐项验证两类图片查看层的缩放、关闭与焦点恢复；验证流程图渲染、缩放、拖动、重置及错误提示。
- 生产构建通过；GitHub Pages 路径正确，旧 URL、图片、相册、`.well-known/assetlinks.json` 与 `tyinstall.html` 仍可访问。
- 记录浏览器端到端验证结果及截图；模拟设备与真机验证须明确区分。
